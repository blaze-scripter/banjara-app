# Banjara App

A mobile-first spiritual/cultural platform for the Hindu Banjara community.

## Tech Stack
- React + Vite
- Tailwind CSS v4
- Capacitor (Android)

## Development
```bash
npm install
npm run dev
```

## Build Android APK
Every push to `main` automatically builds a debug APK via GitHub Actions.
Download from the **Actions** tab → latest workflow run → **Artifacts**.
